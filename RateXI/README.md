# RateXI — แปลงสกุลเงิน

เว็บแปลงสกุลเงินแบบเรียลไทม์ 35 สกุล (บาท ดอลลาร์ ยูโร เยน และสกุลในเอเชีย) ดูอัตราย้อนหลังตามวันที่ได้ถึงปี 1999

## ทำอะไรได้

- แปลงจำนวนเงินระหว่าง 2 สกุล สลับต้นทาง-ปลายทางได้ คัดลอกผลลัพธ์ได้
- อัตราล่าสุดจาก ExchangeRate-API อัปเดตวันละครั้ง (ใส่ key แล้วได้ข้อมูลถี่ขึ้นตามแผนที่สมัคร)
- อัตราย้อนหลังตามวันที่ที่เลือก จาก Frankfurter (ธนาคารกลางยุโรป, European Central Bank (ECB)) ถ้าไม่มีข้อมูลจะใช้ currency-api แทน
- เน็ตหลุดก็ยังใช้ได้ — ใช้อัตราที่เก็บไว้ในเบราว์เซอร์ ถ้าไม่มีเลยใช้อัตราสำรองที่ฝังไว้ในโค้ด และแสดงป้ายว่าออฟไลน์

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป

```bash
npm install
cp .env.example .env   # ไม่บังคับ — ไม่ใส่ key ก็ใช้ endpoint ฟรีได้
npm run dev            # http://localhost:7100
```

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเครื่องพัฒนาของ Vite พร้อม `/api` ในตัว ไม่ต้องรันเซิร์ฟเวอร์แยก |
| `npm run build` | สร้างไฟล์จริงลง `dist/` |
| `npm start` | รันเซิร์ฟเวอร์ Node ที่เสิร์ฟ `dist/` และ `/api` (ต้อง build ก่อน) |
| `npm run preview` | ดูไฟล์ใน `dist/` ด้วย Vite (ไม่มี `/api` — อัตราจะเป็นแบบออฟไลน์) |

## ค่าตั้ง

| ตัวแปร | จำเป็นไหม | ใช้ทำอะไร |
|---|---|---|
| `EXCHANGERATE_API_KEY` | ไม่ | key จาก [app.exchangerate-api.com](https://app.exchangerate-api.com) — ว่างไว้จะใช้ `open.er-api.com` ที่ไม่ต้องใช้ key |
| `PORT` | ไม่ | พอร์ตของ `npm start` ค่าตั้งต้น 7100 |

key อยู่ที่เซิร์ฟเวอร์เท่านั้น เบราว์เซอร์เรียกแค่ `/api/latest/:base` ห้าม commit ไฟล์ `.env`

## โครงสร้าง

```
RateXI/
├─ src/
│  ├─ App.jsx            หน้าจอทั้งหมด: ตัวแปลง เลือกสกุลเงิน เลือกวันที่ ดึงอัตรา
│  ├─ main.jsx           จุดเริ่ม React
│  └─ index.css          Tailwind และฟอนต์
├─ server/
│  ├─ index.js           เซิร์ฟเวอร์สำหรับใช้จริง: เสิร์ฟ dist/ และส่งทุกหน้าที่ไม่เจอไปที่ index.html
│  └─ latest-rates.js    GET /api/latest/:base — ส่งต่อไป ExchangeRate-API และจำผลไว้ 1 ชั่วโมง
├─ vite.config.js        พอร์ต 7100 และ /api ตอน dev
├─ render.yaml           ตั้งค่า deploy บน Render
└─ .env.example
```

ข้อมูลเดินทางแบบนี้:

- **อัตราล่าสุด:** เบราว์เซอร์ → `/api/latest/USD` → ExchangeRate-API · เซิร์ฟเวอร์จำผลไว้ 1 ชั่วโมง และเบราว์เซอร์เก็บใน `localStorage` อีก 1 ชั่วโมง
- **อัตราย้อนหลัง:** เบราว์เซอร์เรียก Frankfurter ตรง ถ้าไม่ได้ผลค่อยเรียก currency-api ผ่าน jsDelivr (ไม่ผ่านเซิร์ฟเวอร์ของเรา)

### API

`GET /api/latest/:base` — `base` เป็นรหัสสกุลเงิน 3 ตัวอักษร เช่น `THB`

```json
{ "result": "success", "rates": { "THB": 32.75, "EUR": 0.863 }, "time_last_update_utc": "..." }
```

ตอบ `400` เมื่อรหัสผิดรูป และ `502` เมื่อดึงอัตราจากต้นทางไม่ได้

## Deploy บน Render

1. push repo นี้ขึ้น GitHub หรือ GitLab
2. ใน Render เลือก **New + → Blueprint** แล้วชี้มาที่ repo นี้ ช่อง **Blueprint Path** ใส่ `RateXI/render.yaml` (ราก repo คือโฟลเดอร์แม่ของ `RateXI/` และ `render.yaml` ตั้ง `rootDir: RateXI` ไว้แล้ว · แผนฟรี, Node 22.12.0)
3. Render จะถามค่า `EXCHANGERATE_API_KEY` ใส่หรือเว้นว่างก็ได้

แผนฟรีของ Render หลับเมื่อไม่มีคนใช้ เปิดครั้งแรกหลังหลับจะช้าไม่กี่สิบวินาที

## เพิ่มสกุลเงิน

แก้รายการ `CURRENCIES` ใน `src/App.jsx` (รหัส · ชื่อ · สัญลักษณ์) ถ้าอยากให้ใช้ได้ตอนออฟไลน์ด้วย ให้เพิ่มอัตราเทียบดอลลาร์ใน `FALLBACK_USD` ไฟล์เดียวกัน

## ข้อจำกัดที่รู้อยู่

- ยังไม่มี test อัตโนมัติ
- อัตราย้อนหลังของ ECB ไม่มีบางสกุล (เช่น LAK, KHR, MMK) และไม่มีวันหยุด — ระบบจะใช้วันทำการก่อนหน้าหรือ currency-api แทน
